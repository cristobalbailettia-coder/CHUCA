## Brand & Style

This design system establishes a high-precision eco-tech operational environment built for community forest surveillance, ecological field reporting, and real-time territorial defense. The design direction merges strict utilitarian minimalism with field-tested functional clarity. 

The aesthetic eschews ornamental greenwashing in favor of structured data density, institutional credibility, and high-readability telemetry. The visual language conveys quiet authority, resilience, and operational discipline—evoking calibrated field equipment, geographic survey panels, and ecological telemetry consoles. Surfaces remain light and crisp to maintain supreme legibility under outdoor ambient conditions, while deep botanical and mineral accents reinforce the arid forest ecosystem without introducing visual fatigue.

## Colors

The palette is anchored by the deep canopy tone of the primary seed `#1B3B2B`, paired with a structured range of ecological and alert tokens that ensure strict WCAG AAA conformance for telemetry readouts.

- **Primary (`#1B3B2B`)**: Deep Pine. Applied to foundational operational controls, primary actions, navigation frame headers, and high-emphasis focal boundaries.
- **Secondary (`#2D5A43`)**: Forest Canopy Slate. Drives secondary surface containers, inactive navigation nodes, metric category identifiers, and sub-actions.
- **Tertiary / Warning (`#D97706`)**: Arid Ochre. Reserved strictly for non-critical incidents, acoustic anomalies, thermal spikes, pending sync states, and perimeter warning telemetry.
- **Neutral Primary (`#0F172A`)**: Deep Slate Charcoal. Utilized for all core headline text, metrics readouts, and primary body typography.
- **Surface Foundations**:
  - `surface-canvas`: `#F8FAF6` (Warm Mineral Sand). Main viewport background.
  - `surface-card`: `#FFFFFF` (Pure Solar White). Elevated inspection tiles and metric blocks.
  - `surface-subtle`: `#F1F5E9` (Muted Sage Sand). Data table headers, search input tracks, and inactive metric wells.
- **Borders & Dividers**:
  - `border-subtle`: `#E2E8F0` (Field Slate Thin). Component segmentations and table dividers.
  - `border-strong`: `#CBD5E1` (Field Slate Mid). Input boundaries and active container borders.
- **Status Accents**:
  - `status-patrol-active`: `#65A30D` (Dry Forest Olive / Active Live Telemetry).
  - `status-alert-critical`: `#DC2626` (Encroachment / Active Deforestation Hazard).
  - `status-info`: `#0284C7` (Remote Sensor Sync / Weather Uplink).

## Typography

Typography is governed by strict utilitarian principles. Inter is utilized uniformly across display, analytical body text, and telemetry metadata.

- **Tabular Figures Requirement**: All data arrays, GPS coordinate readouts, timestamp listings, patrol counters, and telemetry KPIs must enforce OpenType font feature flags `tnum` (Tabular Numbers) and `cv05` to prevent layout shift during live sensor refreshes.
- **Hierarchy Rules**: Metric headers use condensed tracking (`-0.01em` to `-0.025em`) for tight numerical grouping. Micro-labels and telemetry category tags leverage uppercase styling with expanded letter-spacing (`+0.04em` to `+0.06em`) for immediate scannability at small sizes.
- **Reading Comfort**: Body copy is capped at an optimal reading width of 65 characters, maintaining a comfortable 1.5x line height ratio to guarantee zero fatigue during prolonged surveillance shifts.

## Layout & Spacing

The layout is constructed on an 8-point spatial model with 4-point micro-adjustments for compact telemetry grids.

- **Grid Architecture**:
  - **Desktop (1024px+)**: 12-column dynamic fluid layout with `1.5rem` gutters and a fixed `2rem` outer safety margin. Workspaces are structured around an immutable split: fixed 280px left surveillance rail, elastic telemetry body, and contextual 380px inspector drawer.
  - **Tablet (768px - 1023px)**: 8-column grid with `1rem` gutters and `1.5rem` screen margins. Map frames shift above telemetry metrics; secondary drawers collapse to overlay state.
  - **Mobile (< 768px)**: 4-column single-stream stack with `0.75rem` gutters and `1rem` screen margin. Tabular metrics reorganize into single-axis vertical feed strips.
- **Spacing Rhythm**: Internal card padding uses `space-md` for standard telemetry units and `space-lg` for primary surveillance viewports. Form and input clusters maintain a rigid `space-sm` separation to optimize touch and cursor targeting without density dilution.

## Elevation & Depth

Depth is established predominantly through subtle tonal stratification and clean surface boundary rules rather than heavy atmospheric shadows.

- **Base Layer (`Level 0`)**: The application viewport background (`#F8FAF6`). Recessed metrics wells and data-table header bands sink into `#F1F5E9` with a crisp 1px stroke of `#E2E8F0`.
- **Card Layer (`Level 1`)**: Standard metric blocks, charts, and table rows rest on `#FFFFFF` elevated via a 1px border of `#E2E8F0` coupled with an ultra-soft environmental shadow: `0px 1px 2px rgba(15, 23, 42, 0.04)`.
- **Interactive Hover & Overlay (`Level 2`)**: Interactive cards, active patrol tracks, and popover tooltips deploy a refined ambient shadow: `0px 4px 12px -2px rgba(27, 59, 43, 0.08)`, preserving crisp 1px border edges (`#CBD5E1`).
- **Modal Drawers & Threat Alerts (`Level 3`)**: Interactive incident drawers, live GPS command modals, and critical alert sheets leverage high structural depth: `0px 16px 32px -4px rgba(15, 23, 42, 0.12)`, anchored with a solid 1px `#CBD5E1` boundary.

## Shapes

The design system operates at roundedness level `1` (Soft), creating a technical, instrument-grade aesthetic.

- **Base Radius (`0.25rem` / 4px)**: Input fields, checkboxes, radio bounding boxes, action buttons, table row indicators, and micro status chips. This minimal curvature keeps edges crisp and compact for dense data displays.
- **Card & Container Radius (`0.5rem` / 8px - `rounded-lg`)**: Metric summary modules, analytical charts, interactive geo-map viewports, and floating filter docks.
- **Large Container Radius (`0.75rem` / 12px - `rounded-xl`)**: Slide-in inspection drawers, full-screen map modal dialogs, and primary dashboard shell enclosures.
- **Avatars & Indicator Pins**: Micro status pulse dots and geofence map icons maintain full circular morphology (`rounded-full`).

## Components

### Buttons
- **Primary Action**: Background `#1B3B2B`, text `#FFFFFF`, border `none`, corner radius `0.25rem`. Hover state transitions to `#2D5A43`. Active state shifts to `#0F172A`. Focused with a 2px offset outline in `#65A30D`.
- **Secondary Action**: Background `#FFFFFF`, text `#1B3B2B`, 1px border `#CBD5E1`. Hover state shifts surface to `#F1F5E9`.
- **Tertiary / Utility**: Transparent background, text `#2D5A43`, no border. Hover applies `#F1F5E9` text background.
- **Danger Action**: Background `#DC2626`, text `#FFFFFF`. Hover transitions to `#B91C1C`.

### Status Chips & Tags
- **General Architecture**: Height 24px, radius `0.25rem`, padding `0 8px`, typography `label-sm`, letter-spacing `0.06em`, uppercase.
- **Alert (Critical Threat)**: `#FEF2F2` background, `#991B1B` text, 1px `#FECACA` border. Left-aligned 6px static circle in `#DC2626`.
- **Patrol Active (Operational)**: `#F7FEE7` background, `#365314` text, 1px `#D9F99D` border. Left-aligned 6px pulse dot in `#65A30D`.
- **Sensor Alert (Warning / Ochre)**: `#FFFBEB` background, `#92400E` text, 1px `#FDE68A` border. Left-aligned 6px dot in `#D97706`.
- **GPS Inactive / Offline**: `#F8FAFC` background, `#475569` text, 1px `#E2E8F0` border. Left-aligned 6px dot in `#94A3B8`.

### Metric Data Cards
- Container built on `#FFFFFF` with 1px `#E2E8F0` border and `0.5rem` radius.
- Padding structured strictly at `space-md` (16px).
- Internal stack order: Category label (`label-md`, text `#475569`, uppercase) → Telemetry value (`tabular-metric-lg`, text `#0F172A`) → Delta comparison indicator (`body-sm` with contextual green `#65A30D` or amber `#D97706` directional arrows).

### Form Inputs & Select Fields
- Height 36px, radius `0.25rem`, background `#FFFFFF`, border 1px `#CBD5E1`, text `#0F172A`.
- Placeholder text in `#94A3B8`. Focused state: border color `#1B3B2B`, with a 1px shadow glow using `#1B3B2B` at 15% opacity.
- Disabled state: background `#F1F5E9`, border `#E2E8F0`, text `#94A3B8`.

### Checkboxes & Radio Buttons
- 16px × 16px square (checkbox) or circle (radio), radius `0.25rem` for checkboxes.
- 1.5px border `#CBD5E1` on `#FFFFFF` base. Selected state: background `#1B3B2B`, border `#1B3B2B`, with a crisp white centered mark.

### Data Tables
- Row striping eliminated. Header row rendered in `#F1F5E9` with 1px bottom border `#CBD5E1`, typography in `label-sm`, text `#475569`.
- Body rows rendered on `#FFFFFF` with 1px bottom border `#E2E8F0`, height 44px, hovering to `#F8FAF6`. Tabular alignment applied strictly right for numbers, left for entity IDs and community monitor names.

### Interactive Modal Drawers
- Positioned docked to right canvas on desktop (width 400px), full bottom-sheet on mobile.
- Background `#FFFFFF`, left border 1px `#CBD5E1`, level 3 shadow. Header contains fixed incident telemetry metadata, route breadcrumb, patrol telemetry logs, and dispatch confirmation actions.
